# Curriculum and product roadmap

## Python Foundations projects

The complete 19-lesson beginner sequence and six runnable projects are now authored with behavioral checks. Next, add formal rubrics, retrospectives, and chapter assessments.

## Exercise engine expansion

Add multiple-choice checks, output prediction, statement ordering, debugging with failing tests, function contracts, randomized inputs, and multi-step projects. Keep validation behavioral and include edge cases.

## Learning systems

Add spaced review scheduling, chapter quizzes, assessment sessions, study-time tracking, achievement rules, project retrospectives, and skill evidence. Metrics must continue to come from saved learning activity.

## Catalog expansion

Expand in this order:

1. Python Intermediate
2. Computer Science and Problem Solving
3. SQL and Databases
4. Web Development
5. Backend Engineering
6. Data Analysis and Visualization
7. Machine Learning and AI
8. Game Development
9. Software Engineering and Professional Skills

## Career paths

Map shared prerequisites once, then define required courses, optional skills, portfolio milestones, interview practice, competency checklists, and capstones for each career path. Readiness indicators should reflect demonstrated work, not progress percentage alone.

## Additional runtimes

Keep Python available without Docker. Add JavaScript in an isolated worker, then optional local container profiles for other languages. Every runtime should share timeout, output, network, filesystem, and cleanup policies.
